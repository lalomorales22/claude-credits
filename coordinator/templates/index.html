add a machine to the hive

works on mac, linux, jetson, raspberry pi, any old laptop. needs python 3.8+ and ollama (free). the node only makes outbound connections, so there's no port forwarding.

curl -fsSL https://ollama.com/install.sh | sh ollama pull llama3.2 # 3B, runs on a pi 5 or anything with 8GB # bigger machines: ollama pull qwen2.5:14b / gemma3:12b / llama3.1:8b

flags: --name kitchen-mini · --slots 2 (parallel jobs on big machines) · --default-model qwen2.5:14b

linux: sudo systemd-run --unit hive-node --property=Restart=always $(which python3) $PWD/hive_node.py --hive … --key … mac: nohup python3 hive_node.py --hive … --key … > ~/hive-node.log 2>&1 &
